# 후투티 — 상담사를 위한 가진단 도구

임상가·상담자를 위한 증상 소견 기반 가진단(참고용 후보) 보조 웹앱입니다.
DSM-5-TR의 18개 진단 범주에 걸쳐 81개 진단의 체크리스트를 제공합니다.

메인 화면은 **알고리즘 문답**입니다. 구조화 임상면담(SCID 등)의 관문 질문 방식을 따라,
23개 문진 문항에 답하면 확인이 필요한 진단만 골라 정밀 체크리스트로 안내하고,
기간·연령·빈도·기능손상 기준까지 자동으로 판정합니다.
문진 문항은 **내담자에게 그대로 읽어주는 질문이 아니라, 상담자가 관찰·보고를 바탕으로
스스로 판단해 답하는 항목**입니다 — 이 도구는 임상가를 대체하지 않고, 임상가가 판단한
내용을 빠짐없이 기록하고 기준 충족 여부를 자동 계산해 주는 보조 도구입니다.

빌드 과정이나 서버가 필요 없는 순수 HTML/CSS/JS 정적 페이지이며,
입력한 정보는 브라우저 메모리에만 유지되고 어디로도 전송되지 않습니다.

## 중요 — 반드시 읽어주세요

- 이 도구는 **DSM-5-TR(American Psychiatric Association, 2022)의 공식 콘텐츠가 아닙니다.**
  체크리스트 문항은 DSM-5-TR이 다루는 진단 범주·증상군·기간 기준 등의 개념을 참고하여
  **AI(Claude)의 도움을 받아 요약·재서술**한 것으로, 원문을 그대로 발췌하지 않았습니다.
- 위 재서술 내용은 **자격을 갖춘 임상 전문가의 검증을 거치지 않았습니다.** 진단명, 항목 수
  기준(예: "9개 중 5개 이상"), 기간 조건 같은 세부사항에 오류가 있을 수 있으므로, **정확한
  원문 대조는 반드시 DSM-5-TR 자체를 참고**해야 합니다.
- 결과는 어디까지나 **선별(screening)을 위한 참고 정보**이며 진단이 아닙니다. 실제 진단은
  자격을 갖춘 임상가가 면담, 병력 청취, 감별진단 등을 포함한 종합적 임상 평가를 거쳐
  내려야 합니다.
- 자살사고, 자해, 급성 정신병적 증상 등 위기 징후가 있다면 체크리스트 결과와 무관하게
  즉시 전문적 위기평가가 필요합니다.
- 동료나 기관 내에 배포하실 경우, 저작권 및 임상적 책임 관련해 소속 기관의 법무·윤리
  절차를 확인하시길 권합니다. (자세한 배경은 아래 "저작권에 관하여" 참고)

## 사용된 색상

주 색상은 가톨릭대학교 상징색인 "가대 Blue"(Pantone 661 C, HEX #003594)를 기반으로
구성했으며, 보조색으로 화이트·그레이·실버 계열을 사용했습니다.

## 채점 로직 개요

각 진단은 DSM 방식의 "항목군(Criterion group)" 구조로 표현됩니다.

- 각 항목군에는 체크리스트 항목들과 그중 최소 몇 개를 충족해야 하는지(`min`)가 정의되어
  있습니다. (예: 주요우울장애는 9개 항목 중 5개 이상)
- `groupLogic`이 `AND`이면 모든 항목군을 동시에 충족해야 하고, `OR`이면 그중 한 항목군만
  충족해도 됩니다. (예: ADHD는 부주의형 또는 과잉행동-충동형 중 하나만 충족해도 해당)
- 기간 조건(`duration`)과 배제·부가 기준(`other`)은 체크박스로 표현하기 어려운 임상적
  판단이 필요한 부분이라 자동 채점에는 반영하지 않고 서술로만 안내합니다. 실제 판단 시
  반드시 함께 고려해야 합니다.
### 문답의 동작

문항이 대화창에 말풍선으로 하나씩 뜨고, 상담자는 버튼으로 답합니다. **AI가 말을 지어내는
것이 아니라 알고리즘이 정해진 질문을 던지는 것**이라 느려지거나 오류가 나지 않습니다.
답한 문항은 위에 쌓여 지나온 판단을 그대로 되짚을 수 있습니다.

1. **소견 입력(선택)** — 한두 문장을 적으면 관련 문항이 앞으로 배치됩니다. 키워드 매칭은
   **순서만 바꿀 뿐 어떤 진단도 제외하지 않습니다.** 적지 않아도 결과는 같습니다.
2. **문진 23문항** — 18개 대범주 기준이되, 범주 안에 성격이 다른 진단이 섞인 경우
   DSM이 이미 나눠둔 하위 묶음으로 나눴습니다(성격장애 A/B/C군, 신경발달 4묶음).
   답변은 **예 / 아니오 / 확인 안 됨** 3가지이며, "확인 안 됨"은 "아니오"와 다르게
   처리됩니다 — 확인하지 못한 영역은 확인 대상에 그대로 남습니다.
3. **정밀 체크** — "예·확인 안 됨"으로 걸린 범주가 펼쳐진 채로 표시되고, "아니오" 범주도
   삭제되지 않고 접혀 남습니다(관문 질문 하나로 진단을 완전히 배제하지 않기 위함).
4. **기간·연령·빈도·기능손상 확인** — 상위 후보에 대해서만 묻습니다. 81개를 모두 물으면
   문항이 폭발하기 때문입니다. 연령은 한 번만 묻고 모든 진단이 공유합니다.
5. **결과** — 판정은 AI 없이 즉시 계산됩니다. 미체크 항목은 "증상 없음"이 아니라
   **"미확인"** 으로 구분해 표시합니다.
6. **AI 설명(선택)** — 버튼을 누르면 확정된 후보와 근거·판정 결과만 담아 **AI를 한 번**
   호출해 설명 문장을 만듭니다. AI는 판단·계산·후보 좁히기를 하지 않으며, 쓰지 않아도
   도구는 완전히 작동합니다.

### 기간·연령·빈도·기능손상 자동 판정

`js/data.js`의 기간·배제 기준은 사람이 읽는 줄글이라 예전에는 채점에서 빠져 있었습니다.
그래서 우울 증상 5개가 체크되면 그것이 2주짜리든 이틀짜리든 똑같이 표시됐습니다.
지금은 `js/criteria.js`가 그 줄글에서 기계가 판정할 수 있는 부분을 규칙으로 옮겨,
**81개 중 45개 진단**에 대해 자동으로 판정합니다.

판정 결과는 다섯 가지입니다.

| 표시 | 뜻 |
|---|---|
| 충족 | 기준을 만족함 |
| 미충족 | 기준에 못 미침 (그래도 목록에서 빼지 않습니다) |
| 미확인 | 상담자가 아직 입력하지 않음 — 물어보면 채울 수 있음 |
| 직접 확인 필요 | 기준이 수치가 아니라 서술이라 자동으로는 판정할 수 없음 |
| (표시 없음) | 그 진단에 해당 규칙이 없음 |

**미입력은 절대 "충족"이 되지 않습니다.** "2개월 이상 증상 없는 기간이 없어야 함"처럼
계산할 수 없는 조건은 임의로 판정하지 않고 "직접 확인할 것"으로 안내합니다.

규칙의 모든 수치는 `data.js` 원문 안에서 확인할 수 있어야 하며, 이를 자동 대조로
검증합니다. 다만 **규칙이 원문과 일치함은 증명되지만 원문 자체가 임상적으로 옳은지는
증명되지 않습니다** — `data.js`가 미검증 재서술 자료라는 한계를 그대로 물려받습니다.

진행 상태는 같은 탭에서 새로고침해도 유지되며(sessionStorage), 탭을 닫으면 자동으로
사라집니다. 화면의 "처음부터 다시" 버튼으로 언제든 지울 수 있습니다.

### AI에 대하여

AI 엔진은 PC에 Ollama가 설치돼 있으면 그쪽을, 없으면 브라우저 안에서 직접 실행되는
로컬 AI(Kanana GGUF, wllama)를 씁니다 — 최초 1회 약 1.4GB 모델을 내려받고 이후에는
브라우저에 캐시됩니다. 어느 쪽이든 **입력 내용이 서버로 전송되지 않습니다.**

`chat.html`(AI 자유 대화)은 이전 방식으로, 소견을 자유롭게 서술하며 여러 턴에 걸쳐
대화합니다. 대화가 길어지면 문맥 한도를 넘어 오류가 날 수 있어 메인 화면에서 물러났지만,
자유 서술이 필요한 경우를 위해 남겨두었습니다.

파일을 내려받아 `index.html`을 직접 열면 문답·판정·결과 저장은 그대로 동작하지만
**AI 설명은 사용할 수 없습니다** — 브라우저가 파일로 연 페이지의 모듈 로드와 외부 요청을
차단하기 때문입니다. AI까지 쓰려면 웹 주소로 접속하거나 아래 로컬 서버 방법을 쓰십시오.

새 진단을 추가하거나 항목을 수정하려면 `js/data.js`의 배열에 같은 형식으로 객체를
추가·편집하면 됩니다.

## 데이터를 고칠 때 — 점검 도구

`js/data.js`의 진단기준 문구를 고치거나 진단을 추가한 뒤에는 이 폴더에서 다음을 실행하십시오.

```bash
node check.js
```

데이터끼리 어긋난 곳을 찾아 **무엇을 어떻게 고쳐야 하는지 한국어로 알려 줍니다.** 예를 들어

- 기간 문구를 고쳤는데 `js/criteria.js`의 규칙이 옛 문구를 그대로 들고 있는 경우
- 진단을 추가했는데 문진 23문항 어디에도 넣지 않아 화면에 영영 안 나타나는 경우
- 항목 순서를 바꿔 "그중 최소 하나는 반드시" 조건이 엉뚱한 항목을 가리키는 경우
- 답을 하나도 안 했는데 충족으로 나오는 진단이 생긴 경우

**다만 이 도구가 확인하는 것은 데이터끼리 앞뒤가 맞는지까지입니다.** 문구가 DSM-5-TR
원문과 맞는지는 원서를 보고 사람이 판단해야 합니다. 그 진행 상황은
`docsPlan/quantified-criteria/원문대조-진행표.md`에 기록해 두십시오.

원문 문장을 그대로 옮기지 마십시오 — DSM 문장 표현은 APA 저작물입니다.
재서술을 유지하되 정확도만 올리는 방향으로 고쳐 주십시오.

## 저작권에 관하여

DSM-5-TR은 미국정신의학회(APA)의 저작물입니다. 진단명이나 "몇 개 중 몇 개 충족" 같은
사실적 정보는 저작권 보호 대상이 아니지만, 진단기준의 구체적 문장 표현은 APA의 저작물로
보호받습니다. 이 저장소의 체크리스트 문구는 원문을 그대로 복제하지 않고 AI의 도움을 받아
재서술했지만, 임상 전문가의 검증을 거치지 않았고 완전한 무위험을 보장하지 않습니다.
대규모 조직 배포나 상업적 활용을 고려하신다면 APA의 디지털 콘텐츠 라이선스 정책을
확인하시거나 법률 자문을 받아보시길 권장합니다. (본 안내는 법률 자문을 대체하지 않습니다.)
